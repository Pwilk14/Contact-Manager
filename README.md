# Contact Manager
## (WPF + C# + XML)
A simple and functional Contact Manager Application built using C#, WPF and XML for persistant data storage.
  <br>
  One of the first applications I made and many more to come!


## Add Contacts!
<ul>
  <li>Name</li>
  <li>Phone Number</li>
  <li>Email</li>
  <li>Validation for empty fields</li>
  <li>Email format validation</li>
</ul>

## View Contacts!
Displays all saved contacts in a clean readable format.

## Remove Contacts!
Remove a contact by entering their name

## XML data storage
Contacts are saved in an XML file using XDocument and LINQ to XML
